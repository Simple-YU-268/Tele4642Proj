Smart Hotel Internet Access System - Meet Our Team

Technical Background

Powered by Software Defined Networking (SDN)

Hotel Wi-Fi connection issues nowadays

You won't feel surprised when you successfully make network connection in a hotel room. However, for network developers, managing this service—especially with complex customer needs—can be challenging. Guests may require multi devices connection, temporary access, price-based quotas, or premium services. Traditional networking methods struggle to support such flexible, per-user control without complex and costly infrastructure.

Figure: Many devices need hotel network connection

Our Solution

We implement a smart hotel internet access system using Software Defined Networking (SDN). This approach provides programmable control over the network, enabling dynamic traffic management, real-time quota enforcement, and seamless user interaction through a web-based portal.

Why SDN?

Software Defined Networking (SDN) decouples the control plane (decision-making) from the data plane (traffic forwarding). This allows the entire network to be centrally managed by a controller, which can dynamically install and modify flow rules on SDN-compatible switches.

Dynamic Access Control

Dynamically grant or revoke Internet access based on payment status

Flexibility and Programmability

SDN controllers allow developers to write custom logic to support hotel-specific business rules

Better Visibility and Analytics

SDN facilitates granular monitoring of per-user traffic flows, provides hotel administrators with detailed usage statistics

System Workflow Overview

The hotel Internet service operates with a feedback loop between the user, portal server, and SDN controller. The system ensures seamless and secure access control through the following steps:
1

User Connection

When a guest has the need to buy quota, he/she will visit the hotel portal for authentication(using 4-last phone number) and service selection.

2

Portal Interaction & Quota Selection

The guest selects a volume-based access package on the portal. Upon successful online payment, the portal sends the session details (user MAC, room number, chosen quota) to the controller.

3

Flow Rule Allocation

The SDN controller installs flow entries on the switch to allow Internet access for that specific user. It also begins quota tracking—monitoring packet counts via OpenFlow statistics.

4

Real-Time Monitoring & Enforcement

As the user consumes quota, the controller checks against the allocated quota. Once the limit is reached, the controller revokes access by deleting or modifying the flow rules automatically.

Advanced Network Management

Our SDN-based solution provides unprecedented control and flexibility in hotel network management, ensuring optimal user experience while maintaining security and resource efficiency.

Core Functions

The system provides comprehensive network management and user control through four core functional modules.

1. From User Side

Authentication double-check

If room number does not match room number, error message will pop out.

Data Usage Remaining Check

After selecting and purchasing a data plan, their info is sent from the Flask server to the SDN controller. The controller checks if the user has remaining data quota.

2. From Administrator Side

High Visuability

Admins can view all user records, including: Room number, MAC address, Purchased & remaining data quota, Current connection status

Convenient Check-in/out Management

Admins can manually: delete a user, and add a new user with predefined quota

3. From Controller Side

Real-time Monitoring

Controller monitors quota usage every second to avoid excess usage

Network Access Control

System verifies their identity and quota before dynamically installing a flow rule, enabling their access to the hotel network

Implementation Details

How we built the Smart Hotel Internet Access System

Demonstration

Follow these step-by-step instructions to deploy and test the SDN-based hotel Internet access system.

1. Run the Code (all in Ubuntu)

Execute the system components in the following order:
# Terminal 1: Open SDN Controller
ryu-manager hotel_wifi_controller.py

# Terminal 2: Start Server
python3 flask_room_auth.py

# Terminal 3: Start Mininet Topology
sudo python3 mininettopo.py

2. Quota purchasing (all in Ubuntu)

Simulate quota payment via index_room_auth.html:
# Open index_room_auth.html
Input your room number and last 4 digits, click ”Access Wifi”.
After input your digital card information successfully, you can connect to wifi with a certain amount of data usage.

3. Simulate traffic consumption(all in Ubuntu)

Execute the system components in the following order:
# Terminal 3(running Mininet)
h7 iperf -s &
router iperf -c h7 -b 100M -t 30
(h7 means 7-th room in our hotel(room 301), you can change the room number and consumption speed by changing the parameters)

System Requirements

Ensure your system meets the following requirements for optimal performance:

Operating System

Ubuntu 18.04 LTS or later (recommended for compatibility)

Python Version

Python 3.6 or higher with pip package manager

Ryu Controller

Ryu 4.34 or later for SDN controller functionality

Mininet

Latest version for network emulation and testing

Memory

Minimum 4GB RAM, 8GB recommended for large topologies

Network Access

Internet connection for package installation and updates
